# LPS data
>Last modified: 03 Aug 2026

<div style="background-color: rgba(0, 178, 169, 0.3); padding: 5px; border-radius: 5px;"><strong>UK LLC holds data from an increasing number of partner Longitudinal Population Studies (LPS).</strong></div>
<br>

In this section you can read a summary with key metrics about each LPS and you can also drill down to view the list of datasets that UK LLC holds.

<aside class="admonition danger"><p class="admonition-title">Please note that UK LLC does NOT currently hold all of each LPS's datasets</p>We are working with LPS data managers to deposit more data.</aside>
