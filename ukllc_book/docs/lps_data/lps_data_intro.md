# LPS data
>Last modified: 19 Oct 2026

<div style="background-color: rgba(0, 178, 169, 0.3); padding: 5px; border-radius: 5px;"><strong>Key information about the Longitudinal Population Studies (LPS) and their data available in the UK LLC TRE.</strong></div>
<br>

UK LLC holds data from an increasing number of partner Longitudinal Population Studies (LPS). In this section, you can learn more about each LPS and view the datasets currently available through UK LLC.

<aside class="admonition danger"><p class="admonition-title">Please note that UK LLC does NOT currently hold all datasets collected by each LPS.</p>We are working with LPS data managers to make additional datasets available through UK LLC.</aside>

<aside class="admonition note"><p class="admonition-title">The <a 
href="https://guidebook.ukllc.ac.uk/docs/available_linkages/lps_actual_linkages.html" target="_blank" rel="noopener 
noreferrer"><b>Available linkages</b></a> guide outlines which linked data are available for each LPS.</p>Researchers can currently request access to data about LPS participants linked to NHS England records and geographic datasets.</aside>
