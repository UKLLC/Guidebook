## Introduction
UK LLC-managed datasets are available for selection via the **UKLLC** schema in <strong><a href="https://explore.ukllc.ac.uk/" target="_blank" rel="noopener noreferrer">UK LLC Explore</a></strong>.

| [NHS England Reference Datasets](../ukllc_managed_data/datasets/nhse_reference/nhse_reference.md)|Demographic variables, NHS England service use and linkage permissions|NHS England|Latest available|UK LLC|
